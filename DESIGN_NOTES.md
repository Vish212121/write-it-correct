# Gembar browser extension visual identity

Apply these choices across the extension's settings page, popup, selection
toolbar, and in-page issue marks.

## Subject

A proofreading and editing tool. Use red-pen marks, paper, and a confident
single accent rather than generic SaaS dashboard styling.

## Color

- Paper: `#FAF8F5` background
- Ink: `#1C1B29` primary text
- Muted: `#726F82` secondary text
- Line: `#E7E3DB` dividers
- Accent: `#4A3F7A` primary actions and brand
- Accent soft: `#EFEBFA` tints and hover states
- Spelling: `#C9463C`; grammar: `#3574A5`; style and clarity: `#4E8B6B`

Use issue colors only for functional issue marks.

## Type

- Newsreader for headings and the brand wordmark
- Inter for interface text, body copy, and buttons

## Layout

- Settings use a slim left label column and a right content area, with sections
  separated by fine rules instead of repeated cards.
- The in-page toolbar and popup use a compact pill or card, a small monogram,
  and a soft accent-tinted shadow.
- The suggestion panel uses a lightly translucent paper surface. It prefers a
  clear spot away from the editor and visible text, then falls back to a compact
  chip when the page has no clear space; the user can expand it on demand.
- Issue underlines use wavy text decoration in the issue's semantic color.
